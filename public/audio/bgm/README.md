# Pixel Quest BGM Audio Directory

วางไฟล์เสียงประกอบเกม (รูปแบบ `.ogg` หรือ `.mp3` ที่ไม่มีลิขสิทธิ์) ลงในโฟลเดอร์นี้ตามชื่อไฟล์ด้านล่าง ระบบจะตรวจจับและเล่นวนซ้ำแบบ Seamless Loop ให้อัตโนมัติ:

1. `login.ogg` หรือ `login.mp3` — เพลงหน้า Login / เลือกตัวละคร
2. `town.ogg` หรือ `town.mp3` — เพลงเมืองหลัก
3. `field.ogg` หรือ `field.mp3` — เพลงแผนที่เก็บเลเวล
4. `dungeon.ogg` หรือ `dungeon.mp3` — เพลงดันเจี้ยนและหอคอย
5. `battle.ogg` หรือ `battle.mp3` — เพลงต่อสู้มอนสเตอร์ทั่วไป
6. `boss.ogg` หรือ `boss.mp3` — เพลงต่อสู้บอสและเวิลด์บอส
7. `event.ogg` หรือ `event.mp3` — เพลงกิจกรรมพิเศษ

หมายเหตุ: หากยังไม่มีไฟล์เสียงในโฟลเดอร์นี้ ระบบจะใช้เสียงสังเคราะห์ต้นฉบับ (Royalty-free Web Audio Synth) เล่นแทนชั่วคราวโดยไม่เกิดข้อผิดพลาด 404 และสามารถสลับมาใช้ไฟล์จริงได้ทันทีเมื่อวางไฟล์ครบ
